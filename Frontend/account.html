Краткое описание проекта Flip Count

Что такое Flip Count

Flip Count — это сервис для учёта и анализа торговых сделок. Позволяет вести несколько профилей, добавлять сделки, объединять их в крафты и следить за прибылью в реальном времени.

Основные возможности

  • Создание нескольких профилей под разные стратегии
  • Добавление сделок с автоматическим подсчётом прибыли
  • Совмещённые сделки (крафты) с учётом доплат и процентов
  • История сделок с графиками и статистикой
  • Поддержка пользователей и обратная связь

Технологии

Frontend: HTML, CSS, JavaScript. Backend: Java Spring Boot, PostgreSQL, JWT-авторизация.
